iPhone / iPad · Safari

  1. Öffnen Sie diese Seite in Safari.
  2. Tippen Sie auf Teilen. Je nach Safari-Ansicht finden Sie Teilen im Seitenmenü.
  3. Wählen Sie Zum Home-Bildschirm.
  4. Aktivieren Sie Als Web-App öffnen, falls angezeigt, und tippen Sie auf Hinzufügen.

Über Ihr Browsermenü

  1. Öffnen Sie diese Seite direkt in Ihrem Browser, außerhalb einer anderen App.
  2. Suchen Sie im Menü nach App installieren oder Zum Startbildschirm hinzufügen. Auf dem Mac bietet Safari Datei → Zum Dock hinzufügen.
  3. Bestätigen Sie die Auswahl. Danach öffnen Sie LogoBoss über das neue Symbol.

Die angebotene Installation hängt von Ihrem Browser ab. Sie können den Support jederzeit direkt über die Website nutzen.
